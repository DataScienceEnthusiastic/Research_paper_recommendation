How It Works

1. Feature Extraction: Each paper's title and abstract are converted into a numerical vector using TF-IDF (word importance scoring).

2. Similarity Search: Cosine similarity measures the angle between paper vectors. Smaller angle = more similar content.

3. Global Clustering: All papers are grouped into topic clusters using K-Means (with optimal K determined by silhouette score). The cluster map shows the full research landscape.
